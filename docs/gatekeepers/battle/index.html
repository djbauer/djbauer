Prototype for the Gatekeepers design draft. Every battle is a deterministic simulation: the same orders and the same seed always give the same result, so a server can run it once and every player watches the same replay. House abilities and house ships are first guesses at balance.

How to play

You set orders ahead of time; the battle then fights itself. The same orders and the same dice always give the same battle.

1 · House

  • Each house has a battle ability and one ship nobody else can build.
  • Varkas is tough, Nyx sees enemy orders, the Synod never retreats, and so on.

2 · Formation

  • Nine slots: three lanes, each with rear, line and vanguard.
  • The vanguard is shot first. Screen fragile ships behind sturdy ones.
  • Every hull costs points, and your fleet has a points budget.

3 · Doctrine and retreat

  • Doctrine changes how ships fight (advance, hold, focus fire and so on).
  • Retreat: when your losses reach this share, the fleet jumps out.

4 · Engage

  • Watch the battle, read the report, then change your orders.
  • Rematch keeps the enemy and the dice, so only your choices change the result.
  • New opponent rolls a fresh enemy fleet you can't see yet.
